## ALGORITHMES

- une suite finie d'instructions permettant de résoudre un problème
- chaque instruction est non ambigu et executable
- un algo se termine toujours (il n'est pas infini)
- il produit un résultat a partir de donnees d'entree

**Schema fondamental**

- -> entrees -> traitement -> sorties

**Pseudo-code**

- langage intermédiaire entre le fr et le code
- syntax simplifiée et normalisée
- indépendant de tout langage de prog
- permet de se concentrer sur la logique algo
- utilise dans les examens et les entretiens techniques

_**les mots clés du pseudo code sont écrites en maj**_

**Les types de donnes**

- ENTIER : nombre entier (positif et négatif)
- REEL : nombre a virgule (positif et négatif)
- CHAINE : Text (entre "")
- BOOLEAN : Valeur logique (VRAI, FAUX)
- CHARACTER : un seul caractère (ex: "A")

`le type determine les operations possibles`
`le type determine l'espace mémoire`

`une variables est un espace nommé en mémoire qui contient une valeur`

`camel-Case, pas d'espace, pas de caractères spéciaux, tout les mots réservés du langages sont en maj`
