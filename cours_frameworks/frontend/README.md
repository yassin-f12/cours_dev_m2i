# TechCorp RH

Application de gestion des ressources humaines développée avec Angular dans le cadre du cours sur les frameworks.

## Prérequis

- Node.js 24
- npm (installé avec Node.js)

Pour vérifier les versions installées :

```bash
node -v
npm -v
```

## Installation

Depuis le dossier `frontend`, installer les dépendances :

```bash
npm install
```

## Serveur de développement

Lancer l'application avec :

```bash
ng serve
```

Ouvrir ensuite [http://localhost:4200/](http://localhost:4200/).

L'application se recharge automatiquement lors des modifications des fichiers source.

## Commandes utiles

Vérifier le code avec ESLint :

```bash
ng lint
```

Lancer les tests unitaires sans mode surveillance :

```bash
ng test --watch=false
```

Construire l'application pour la production :

```bash
ng build
```

Les fichiers générés sont placés dans `dist/techcorp-rh`.

## Technologies

- Angular CLI 22.2.3
- TypeScript
- HTML et CSS
- ESLint
- Vitest pour les tests unitaires
